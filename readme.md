<h1>Heart Disease Detection</h1>

<h2>📌 Description</h2>
<p>
A supervised machine learning project that predicts the presence of heart disease using health-related features such as age, BMI, blood pressure, diabetes, cholesterol, smoking, and lifestyle factors.
The project uses Logistic Regression, along with Label Encoding and Standard Scaling, and evaluates the model using accuracy, classification report, and confusion matrix.
</p>

<p><b>Model Accuracy:</b> 92.63%</p>

<h2>🛠️ Tools and Technologies Used</h2>
<ul>
    <li>Python</li>
    <li>Pandas</li>
    <li>Scikit-learn</li>
    <li>Linear Regression</li>
    <li>Joblib</li>
</ul>

<h2>📊 Dataset</h2>
<p>
The dataset contains health-related patient records labeled as Heart Disease and No Heart Disease. Categorical features are transformed into numerical values using LabelEncoder, while features are standardized using StandardScaler before being used for model training and prediction.
</p>

<p>
<b>Dataset Link:</b>
<a href="https://www.kaggle.com/code/moridata/heart-disease-dataset/input">
Kaggle Dataset
</a>
</p>

<h2>📈 Model Performance</h2>
<ul>
    <li>Algorithm: Linear Regression</li>
    <li>Accuracy: 92.63%</li>
    <li>Train-Test Split: 80-20</li>
    <li>Feature Extraction: CountVectorizer</li>
    <li>Classification: 0 for No Disease | 1 for Disease Exists</li>
</ul>
